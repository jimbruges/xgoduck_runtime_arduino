Bluetooth —

Pair new controller searches for 60 s and pairs the first gamepad that starts advertising: click it, then put the controller in pairing mode (GameSir Nova Lite: from off, press A + Home until the LED fast-blinks yellow). Or Scan and use Pair & connect on a listed device. A paired controller is trusted and reconnects by itself when switched on.

Use the controller's Android or generic HID mode. This board's kernel has no PlayStation or Nintendo drivers, so modes that imitate a DualShock 4 (often labelled PC or PS4) or a Switch Pro controller pair but send no input. On the GameSir Nova Lite, PC mode (B + Home, blue) is a DualShock 4 imitation; Android mode (A + Home, yellow) works.

Live input no controller

Press a button or move a stick to see its name here; the matching mapping row lights up below. Calibration and Servo setup ignore the controller. While a controller is connected its sticks override the Control page joysticks, and it keeps Default pose and Walk enabled without the page open. If it disconnects, motion stops and the robot disarms after 1 s unless a page is open.

Button mapping

Stick and trigger mapping

Forward, strafe and turn are scaled to the walk limits (vx ±0.4, vy ±0.3, ωz ±1.0). Use Invert when a stick moves the robot the wrong way, and Trigger for an analog trigger that rests at −1 so it maps to 0…1. Hold actions (open mouth, half speed) apply only while the button is held; the others fire once per press.
